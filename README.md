# Gemara Test 2 practice

Adaptive practice for a 10th-grade Gemara test: the Jewish calendar, the Mesorah, Shas and the daf, Intro to Pesachim, the first Mishna and Rashi, why we do bedikah if bittul works, and the halachos of bedikas chametz. Multiple choice and matching, three levels per topic, hints, and a "what to work on" panel. Progress is saved in your own browser.

Open it: https://eyallowy-stack.github.io/gemara-test2-practice/
